Install

Two commands in either client. The plugin installs as one folder: 11 skills, the jury agent, the hooks, the corpus, 89 recipe entries and the scripts they share.

Claude Code

  1. /plugin marketplace add burgisimon/awards
  2. /plugin install awards@awards

Codex

  1. codex plugin marketplace add burgisimon/awards
  2. codex plugin add awards@awards

Start a build

Start a new Claude Code session in an empty folder and ask for the site in your own words: the subject, who it is for and what a visitor should do. /awards:craft is the explicit entry point for a whole site and /awards:component for one element; an award-framed request reaches craft on its own.

Codex names the same skills with a dollar sign: $awards:craft, $awards:component, $awards:jury. Codex loads none of the hooks, so the audit runs when a skill calls it, after each batch of edits.

Expect a long, mostly unattended run rather than a chat. The first jury verdict is usually fix, with a short, located list; ship applies it and the jury checks once more.

npm and network accessany current npmInstalling the website project's own dependencies.
  1. npm install --global playwright@1.64.1
  2. npx playwright install chromium

A project-local install works too once the project exists. To use a Playwright installed elsewhere, point AWARDS_PLAYWRIGHT at its project folder; AWARDS_CHROMIUM can name a Chromium executable. Linux and cloud hosts may need the browser's system libraries as well, which the first command below installs. The static audit and the scaffold run without a browser.

Before a build, the environment check reports what is missing, from the website project's folder. It installs nothing and changes no configuration.

  1. npx playwright install --with-deps chromium
  2. node <plugin>/scripts/doctor.mjs . --json

What it writes in your project

AWARDS.md
The brief, the direction contract, the page map, the motion score, budgets, the jury and ship logs, and every accepted exception.
DESIGN.md
The visual system: tokens and the rules for using them, kept identical to src/styles/tokens.css.
.awards/
Captures, jury reports, ship reports and the audit's JSON. Keep the captures out of version control.

Cloud sessions and Cowork

Cloud sessions do not inherit plugins enabled only in your local settings. In the website repository, add the awards marketplace under extraKnownMarketplaces in .claude/settings.json, set "awards@awards": true under enabledPlugins, and commit it; provision Node and the browser dependencies in that environment too.

For Cowork, install the whole plugin through Customize, then Plugins. A terminal install does not reach Cowork, and single skill folders do not work alone: they share the corpus, recipes, scripts and templates at the plugin's root.

From a local copy

To try a checkout without the marketplace, load the plugin folder for one session.

  1. git clone https://github.com/burgisimon/awards
  2. claude --plugin-dir awards/plugins/awards
