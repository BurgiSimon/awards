Install

Two commands in either client. The plugin installs as one folder: %%skills%% skills, the jury agent, the audit hook, the corpus, %%recipes%% recipes and the scripts they share.

Claude Code

  1. /plugin marketplace add burgisimon/awards
  2. /plugin install awards@awards

Start a whole site with /awards:craft, or one element with /awards:component. Every other skill also answers its own kind of request: ask for a critique and the jury runs.

Codex

  1. codex plugin marketplace add burgisimon/awards
  2. codex plugin add awards@awards

Codex names skills with a dollar sign. Three prompts to begin with:

  • $awards:craft Build an award-worthy website.
  • $awards:component Improve this component.
  • $awards:jury Review this page.

Codex has no edit hook, so the audit runs when a skill calls it.

Requirements

Node
20.19 or later on the 20 line, or 22.12 or later, for Vite builds.
Playwright and Chromium
For captures, the rendered audit and jury evidence. Install them in the website project. The static audit and the scaffold run without them.
  1. npm install --save-dev playwright
  2. npx playwright install chromium

The craft skill checks the environment once before it builds anything. The check reports what is missing; it installs nothing and changes no configuration.

What it writes in your project

AWARDS.md
The brief, the direction contract, the page map, the motion score, budgets, the jury and ship logs, and every accepted exception.
DESIGN.md
The visual system: tokens and the rules for using them, kept identical to src/styles/tokens.css.
.awards/
Captures, jury reports, ship reports and the audit's JSON. Keep the captures out of version control.

From a local copy

To try a checkout without the marketplace, load the plugin folder for one session:

  1. git clone %%repo%%
  2. claude --plugin-dir awards/plugins/awards
