# Notice

**Provenance.** The workflow shape of this plugin (one orchestrating skill, durable project files, a direction contract written before code, a craft floor, a fresh-context reviewer, distribution as a plugin) was inspired by the open-source *impeccable* skill by Paul Bakaus (MIT). Its public slop catalogue served as a checklist of categories for this plugin's own slop scan (`references/anti-patterns.md`). No text, detector code or asset from impeccable is reproduced here; the prose, rules, scripts and recipes in this repository were written for this project.

**The reference corpus.** The site cards in the plugin’s `references/sites/` describe twenty published websites and the studios that made them. Those sites, their copy, imagery, code and brands belong to their authors. The case studies were compiled from public award listings, published case studies, open-source repositories and reconstructions, and each fact carries a confidence label. They exist so the skills can learn principles; the skills refuse to reproduce a reference's layout, copy, palette or assets, and the jury's specificity test fails any build a juror could trace to a source site.

**Original demonstration artwork.** Alder Workshop and its white-oak bench, Kiln Nine, Tidal Notes, and Form & Sound are fictional examples; their specifications, locations, events and product claims are synthetic demonstration material. The five Alder Workshop images in `recipes/_shared/composition/` and the four raster benchmark images in `evals/visual/` were created for this project using built-in image generation, with no external reference artwork. Later views use the first original in their family as a material and lighting reference. Form & Sound’s two SVG graphics are original native artwork. Asset-local `ASSETS.md` files record provenance, delivery processing and exact raster prompts. These examples imply no affiliation or endorsement.

**Fonts.** The corpus names licensed typefaces where sites used them. The plugin never ships font files; its recipes use system stacks, and its reference lists point to open-licence faces first and name licensed faces only as options to license.

**Libraries.** GSAP (Webflow / GreenSock, standard "no charge" licence for its full plugin set since 3.13), Lenis (MIT), Three.js (MIT), anime.js (MIT), postprocessing (Zlib), taxi (BSD-3-Clause) and Vite (MIT) are dependencies of the recipes only and are installed by the user.
