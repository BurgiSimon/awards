/ ladder

Letters flicker in.

Each glyph runs an opacity ladder [0, 1, 0, 0, 1, 1] with a 40 ms stagger, so the line switches on like a tube light rather than fading. On hover, the same ladder replays with an expo-out shift. The source text stays intact for assistive technology; the glyph spans are decoration.
