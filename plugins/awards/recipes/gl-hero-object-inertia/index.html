/ one object

One object,
with weight.

A single hero object with pointer inertia and a scroll-scrubbed turn. The pointer sets a target orientation; the object follows through a damped spring, so it overshoots and settles like a thing with mass. Lit by a generated matcap: no textures, no HDRI, no download.

Below the hero.

Scroll turns the object a full revolution across the first two viewports; the inertia keeps responding while it turns.
