/ synthetic demo

Four channels,
drawn in order.

The branches below are drawn into a mask at load. Each texel stores which branch it belongs to and how far along that branch it sits, so one progress value per branch reveals them all, staggered, in a single pass.

Scroll to grow the channels · 0%

Rules

  • The mask is generated from four cubic Bézier branches: R holds the branch id, G and B a 16-bit arc length (0 at the start, 1 at the end), A the distance from the centreline.
  • One uniform array carries a progress per branch; the scroll drives a single value that is split into four staggered windows.
  • The visible front is the arc length plus a feather bowed by the edge distance, so the head rounds like a cap.
  • Reduced motion: every branch is drawn complete and nothing grows. Static: one frame, complete.
