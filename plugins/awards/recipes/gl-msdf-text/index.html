/ gl-msdf-text · booting

/ 01 · the headline

Type, in the scene.

The heading above is real text: selectable, in the accessibility tree, and the thing that decides the layout. The glyphs you can see are drawn in WebGL from a distance-field atlas built in this tab, at this size, from the same system font — no atlas file, no font file, no glyph baked at a fixed size.

/ 02 · the field

Distance, not pixels.

A glyph is rasterised once into a padded cell, then every pixel is asked how far it is from the nearest edge — a Felzenszwalb distance transform, two passes, about sixty lines and no dependency. The signed result is stored in all three colour channels, so the fragment shader takes median(r, g, b) exactly as it would with a real three-channel atlas from msdf-bmfont: drop one in and nothing else changes.

fwidth turns that distance into a screen-space edge width, which is the whole trick — one texture stays crisp at any scale, and the headline can be thrown at the camera without turning to mush. The honest limit: a single-channel field rounds sharp corners, so a true MSDF atlas still beats this on a serif's spurs.

/ 03 · the mirror

The canvas is not the text.

The canvas carries aria-hidden and the string lives in the DOM as the heading it claims to be. Drop to the DOM text with the button above and the same words stay in the same place, ink restored, WebGL disposed — which is also what a visitor with no WebGL, or the static motion tier, gets on the first frame.
