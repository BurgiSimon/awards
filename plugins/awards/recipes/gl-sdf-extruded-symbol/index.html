/ gl-sdf-extruded-symbol · svg

/ synthetic demo

A flat mark,
given a body.

The symbol is a two-dimensional distance function: a ring crossed by a bar. One fragment shader pushes it into depth, rounds its edge into a bevel and marches a ray through it, so the object has no model file at all.

Rules

  • The mark is a 2D signed distance: a ring and a capsule, joined with min.
  • Extrusion pairs that distance with the slab depth; shrinking first and subtracting the bevel after rounds every edge.
  • The ray is clipped to the mark's box, then marched with a fixed step budget; normals and occlusion take four taps each.
  • Metal is reflection only: a studio ring environment, a Schlick tint, inline ACES and gamma.
  • Reduced motion, static, no WebGL2 or a lost context: the SVG strokes stay, the canvas never shows.
