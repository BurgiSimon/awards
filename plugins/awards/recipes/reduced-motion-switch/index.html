tier: full

/ one switch

Three tiers,
one decision.

The page asks motionTier() once and every effect branches on the answer: full is the authored score, reduced keeps state changes and drops spatial movement, static settles everything on load. A user override lives on <html data-motion>.

Demonstration

  • full orbit loops, panels slide in, marquee runs
  • reduced orbit parked, panels fade, marquee is a static row
  • static everything already in its end state; no ticker subscribed
