Corvid 4.0, the Thaw release

Forty-eight changes to the Corvid groovebox: the sequencer, the voices, the effects, MIDI, the interface, and the fixes. Every note is on this page; search reads the page itself.

Sequencer

Steps, timing and the order patterns play in. 8 changes

  1. Ratchets per step

    Each step can repeat two to eight times inside its own length; hold Shift and turn the step's knob.

    • steps
    • timing

  2. Probability on every step

    Give any step a chance from 0 to 100 percent, in tens, so a pattern never plays quite the same way twice.

    • steps
    • generative

  3. Pattern chains up to 64

    Chain up to 64 patterns into a song and edit the chain while it plays.

    • song
    • patterns

  4. Swing per track

    Swing now lives on each track, from 50 to 75 percent, instead of on the whole machine.

    • timing
    • groove

  5. Euclidean fill

    Spread a number of hits as evenly as possible across a track's length with one gesture.

    • generative
    • steps

  6. Micro-timing for steps

    Nudge any step up to half a step early or late, in twenty-fourths.

    • timing
    • steps

  7. Reverse and ping-pong play

    Tracks can play backwards, or bounce between their first and last step.

    • patterns
    • direction

  8. Copy a page to every track

    Copy the visible sixteen steps to every track at once, keeping each track's own notes.

    • editing
    • patterns

Voices

Oscillators, filters, envelopes and the sampler. 8 changes

  1. Wavetable morphing

    The second oscillator scans 64 wavetables, and the morph position can be modulated like any other knob.

    • oscillator
    • wavetable

  2. Unison up to eight voices

    Stack up to eight detuned voices per note, with a spread from 0 to 50 cents.

    • oscillator
    • polyphony

  3. Filter key tracking

    The filter cutoff can follow the note played, from 0 to 100 percent.

    • filter
    • modulation

  4. Ladder filter model

    A four-pole ladder filter joins the state-variable one, with a drive stage in front of it.

    • filter
    • drive

  5. Looping envelopes

    Envelopes can loop between decay and release, which turns them into slow, shaped modulators.

    • envelope
    • modulation

  6. Velocity curves

    Choose a soft, linear or hard response to velocity, on the pads and over MIDI.

    • velocity
    • pads

  7. Voice stealing choices

    Pick oldest, quietest or none when every voice is already playing.

    • polyphony

  8. Sample start modulation

    Modulate where a sample starts playing, for drum loops that shuffle themselves.

    • sampler
    • modulation

Effects

Delay, reverb, dynamics and the mix. 8 changes

  1. Tape delay with wow

    A tape-style delay with wow, flutter and saturation, synced to the tempo or free.

    • delay
    • tape

  2. Shimmer reverb

    A reverb that pitches its tail up an octave, with its own mix knob for the shimmer.

    • reverb

  3. Sidechain from any track

    Duck any track's level from any other, with attack and release set in milliseconds.

    • dynamics
    • mixing

  4. Bit crusher per track

    Reduce sample rate and bit depth on a single track instead of on the master.

    • distortion

  5. Post-fader sends

    Sends can take the signal after the track fader, so muting a track also mutes its echo.

    • mixing

  6. Freeze buffer

    Hold the last beat in a buffer and loop it while the pattern carries on underneath.

    • performance
    • looper

  7. Master compressor presets

    Three starting points for the master compressor: glue, punch and transparent.

    • dynamics
    • master

  8. Stereo width per track

    Narrow or widen each track's stereo image, from mono to twice its width.

    • mixing
    • stereo

MIDI

Controllers, clocks and other machines. 8 changes

  1. MPE input

    Per-note pitch bend, pressure and slide from MPE controllers now reach each voice.

    • controllers
    • expression

  2. Clock out over USB

    Send MIDI clock to a computer over USB as well as from the five-pin port.

    • sync
    • usb

  3. Program change per pattern

    Each pattern can send a program change to external gear as it starts.

    • patterns
    • external

  4. MIDI learn for every knob

    Hold a knob and move a controller to map it; the maps are saved with the project.

    • controllers
    • mapping

  5. Thru filtering

    Choose which channels pass from MIDI in to MIDI out.

    • routing

  6. Follow start and stop

    Corvid can follow start, stop and song position from an external clock.

    • sync
    • transport

  7. Arpeggiator to MIDI out

    The arpeggiator's notes can be sent out to other machines instead of played inside.

    • arpeggiator
    • external

  8. Project backup as sysex

    Back up a whole project as a sysex dump to any MIDI recorder.

    • backup
    • projects

Interface

The screen, the pads and the keys. 8 changes

  1. Larger step figures

    The step display uses a larger set of figures that can be read from across a stage.

    • display
    • legibility

  2. Brightness-coded pad palette

    An optional pad palette that tells tracks apart by brightness as well as by hue.

    • pads
    • legibility

  3. Undo for 32 edits

    Undo and redo the last 32 edits, deleted patterns included.

    • editing

  4. Find a project by name

    Type a few letters on the pads to jump to a project in the browser.

    • projects
    • browser

  5. Pads dim when idle

    After ten idle minutes the pads dim to a tenth of their brightness.

    • display
    • power

  6. Fine mode for knobs

    Hold Shift while turning any knob for steps ten times finer.

    • editing
    • knobs

  7. Track names

    Name each track with up to twelve characters; the names show on the screen and in exports.

    • tracks
    • display

  8. Help overlay

    Hold the Help key to see what every lit control does on the current page.

    • learning
    • display

Fixes

What used to go wrong and no longer does. 8 changes

  1. Clock drift at fast tempos

    Fixed a drift of up to 2 ms per bar above 180 BPM when synced to an external clock.

    • sync
    • timing

  2. Stuck notes on pattern change

    Notes held across a pattern change now always receive their note off.

    • midi
    • patterns

  3. Clicks on 24-bit WAV import

    24-bit WAV files no longer import with a click at the start.

    • sampler
    • import

  4. Pad latency

    The time from a pad press to sound is down from 6 ms to under 3 ms.

    • pads
    • timing

  5. Saving during a power cut

    A project being saved when the power is cut is no longer corrupted.

    • projects
    • power

  6. Screen flicker in the cold

    Fixed a flicker of the screen in rooms below 10 degrees.

    • display

  7. Arpeggiator octave reset

    The arpeggiator returns to its first octave when the pattern restarts.

    • arpeggiator

  8. USB audio dropouts

    Fixed dropouts in USB audio after the computer sleeps and wakes.

    • usb
    • audio
