/ house easing

One curve,
every hand.

The curves and durations are written once, as CSS custom properties. On boot each curve is registered as a GSAP CustomEase and the house curve becomes gsap.defaults(), so a tween that names no ease, a CSS transition and a named tween all move the same way.
