/ filmstrip-index-rows

Every reel at
one speed.

Each project runs as its own strip of frames. The duration comes from the measured strip width, so long and short reels travel at the same 70 px/s. A row stops on hover, on focus and off-screen; one link per project, the frames are decoration. Projects and frames are synthetic.

  1. Saltmarsh Ferry Wayfinding for a tidal crossing View project

  2. Kiln Row Ceramics Packaging for a shared studio View project

  3. Northlight Observatory A night-sky visitor guide View project

  4. Ossa Running Club Identity for a dawn league View project

  5. Pellmell Radio Schedules for a pirate station View project

  6. Verdigris Hotel Signage for a copper-roofed inn View project

Rules

  • Duration is measured width over one speed token: copy width / 70 px/s, recomputed on resize.
  • One link per project; the reel is aria-hidden, so Tab stops six times for six projects.
  • A row pauses on hover, on focus inside it and while off-screen.
  • The hover clip mounts only for (hover: hover), full motion and an on-screen row; here it is a synthetic canvas stream.
  • Under reduced motion every reel is at rest and nothing grows.
