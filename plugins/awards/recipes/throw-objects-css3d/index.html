/ throw-objects-css3d

/ toy

Pick it up.
Let it fly.

Three extruded blocks sit on a shelf. Drag one and let go mid-swing: it keeps the speed of your hand, tilts into the direction it travels, and drops into the tray if it gets there. Every block has a button that throws it for you.

Rules

  • Draggable type: "x,y" with inertia: true, bounded by the stage: the release velocity keeps the block moving after the pointer lets go.
  • A snap.points function reads the landing point; a block landing in the tray is pulled to its slot, anywhere else it stays where it stops.
  • Tilt follows InertiaPlugin.getVelocity on an inner body, so the drag transform and the tilt never fight.
  • Each block has a real button that throws it to the same slot. Under reduced motion a drop lands where it is released and the buttons place blocks instantly.
