/ boot-lenis-gsap

One clock.Every motion.

Lenis smooth scroll driven by GSAP's ticker, ScrollTrigger kept in sync, fonts awaited before text splits, a reduced-motion tier, and the window.__awards hook the review tools use.

/ 01

Reveal once, on entry.

Each chapter enters through a masked line reveal the first time it crosses 80% of the viewport. It never replays: the page should feel authored, not looping.

/ 02

Scrub is linear.

The progress readout in the header is scrubbed with ease: 'none'; the smoothing comes from Lenis' lerp, never from the tween's ease.

/ 03

Reduced motion is a tier.

Under prefers-reduced-motion the lines still appear, by opacity, in a third of the time. Nothing is hidden behind an animation that will never run.
