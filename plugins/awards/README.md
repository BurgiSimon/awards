# awards plugin

Version **1.0.0**. See the [release notes](https://github.com/burgisimon/awards/blob/main/CHANGELOG.md).

Skills, agent, hook, reference corpus, recipes and scripts for building award-worthy websites and components with Claude Code and Codex. Start with `/awards:craft` for a whole site or `/awards:component` for a single element in Claude Code; use `$awards:craft` or `$awards:component` in Codex. Every other skill also triggers on its own request. See the [installation instructions](https://github.com/burgisimon/awards#install) and [Codex runtime guidance](references/codex.md).

Install this whole folder; individual skills depend on its shared resources. Use Node 22 LTS (22.12+) or 24 LTS; 20.19+ still runs Vite builds but is past end of life, and the framework stacks need 22. Captures and jury evidence need Playwright before the website project has a `package.json` (the hero probe runs in phase 3), so install it once globally (`npm install -g playwright@1.64.1 && npx playwright install chromium`) or point `AWARDS_PLAYWRIGHT` at a folder that has it; a project-local install works too once the project exists. The static audit and scaffold do not require Playwright. Both client manifests live here; [LICENSE](LICENSE) and [NOTICE.md](NOTICE.md) travel with the installed package.

- `skills/` — the eleven skills (`craft`, `concept`, `system`, `structure`, `stack`, `motion`, `webgl`, `component`, `jury`, `ship`, `research`).
- `agents/awards-jury.md` — the fresh-context jury.
- `hooks/hooks.json` — a quick craft-floor audit after Claude Code edits, active only in projects that have an `AWARDS.md`, a one-line route hint on prompts that name award framing, a state card from an unfinished build's `AWARDS.md` after a context compaction, and a check that sends a jury reply without its `disposition:` line back once; `AWARDS_HOOK=0` or the `hooks_enabled` setting silences all four. Codex loads none of them (its manifest declares `"hooks": {}`) and runs the audit explicitly.
- `references/` — the corpus: 65 site case studies, each fact labelled by how it was verified, the [house tells](references/patterns/house-tells.md) this plugin's own builds converged on, the [visual composition guide](references/patterns/visual-composition.md), the wider pattern language, the jury rubric and stack notes.
- `recipes/` — 98 focused recipes plus one complete composition (99 browser-verifiable entries); six visual examples carry reviewed desktop/mobile images of synthetic demonstration material. Generated and tested does not imply human preference. `recipes/README.md` is the catalogue by intent.
- `scripts/` — `doctor.mjs` (early environment check), `capture.mjs` (Playwright screenshots at desktop, tablet and phone, ARIA trees, [interactive states](references/capture-states.md), held-clock timelines, throttled and GPU passes, baseline diffs, a keyboard and thumb walk with `--walk`, picture share per frame), `audit.mjs` (deterministic checks), `assets.mjs` (the asset and licence log, and `search` / `get` over open collections), `crux.mjs` (field data for a live site), `new-project.mjs`, `roll.mjs` (seeded deals of directions, engines, stimuli and options), `verify-recipes.mjs`, and for upkeep `house-ledger.mjs`, `contrast-set.mjs`, `check-versions.mjs`, `calibration.mjs`, `check-sync.mjs`, `lint-refs.mjs`.
- `assets/templates/` — `AWARDS.md`, `DESIGN.md`, jury and ship report templates, an authored 404; `assets/scaffold/vite-vanilla/` is what `new-project.mjs` copies.
- `evals/` — the `claude plugin eval` suite (smoke, contract, resume, route, coexist and build tiers), `behavior.mjs` (live browser/tool regressions), `codex-install.mjs` (installation and discovery) and `tournament.mjs` (blind rounds between arms, [protocol](evals/visual/tournament.md)); all three run without model calls. See [verification commands](evals/README.md#behavior-regressions).
