# Original generated raster assets

Created 2026-09-22 using the built-in image-generation tool, one call per image, four benchmark calls total. These are synthetic demonstration images, not photographs of real products or locations. No external reference artwork was supplied. The second image in each pair used the first generated image as its material, light and palette reference. No additional generation occurred after selection.

Delivery processing: native Chromium canvas re-encoding to WebP at quality 0.88, preserving the full 1536 × 1024 composition without resizing or retouching. Re-encoding omits embedded execution metadata from repository deliverables; original PNGs and raw provenance remain in the external benchmark archive. Each final file is below 1 MiB.

## Asset use

- `assets/collection.webp`: the full three-piece collection, suitable for an overview. Preserve all three silhouettes in a collection view; a tight mobile crop must not imply a missing piece.
- `assets/glaze-detail.webp`: pale chalk bowl rim, iron flecks and glaze texture. Detail image, not a separate product.
- Light comes softly from the side; limestone and warm clay tie both images together. Keep visible contrast between the pale ceramics and surrounding page.
