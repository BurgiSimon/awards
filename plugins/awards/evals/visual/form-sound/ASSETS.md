# Original graphic assets

Created 2026-09-22 as native SVG code for this benchmark. No source artwork, external reference, font file or generated raster was used. Form & Sound and all event details are synthetic demonstration material. The graphics are original arrangements of arcs, a disc and system-font text; they are not traced from an existing identity.

- `assets/poster.svg`: 900 × 1200. Cream field, dark open arcs, coral disc, event title and dates. Use as an event artifact; preserve legible wording rather than cropping it to imply different details. System sans-serif text may vary slightly across environments, so use the same browser and installed fonts for both arms.
- `assets/mark.svg`: 320 × 320, transparent background. Text-free open arcs and coral disc. Use with an accessible brand name in adjacent HTML or an appropriate image alternative.

Graphic direction: the repeated arcs suggest listening; the disc interrupts their rhythm. Neither file prescribes the webpage's layout. No third-party trademark affiliation or endorsement is claimed.
