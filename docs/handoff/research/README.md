# Raw research reports

The unedited final reports of the research agents that analysed the nineteen sites (wave 1, batches A–C, through web search; wave 2, batches D–E, through GitHub sources and recall after the search budget ran out) and the report of the planning agent that validated the architecture.

These are **inputs**, not plugin material: the site cards in `plugins/awards/references/sites/` are the distilled, confidence-labelled versions. Keep the caveats each report opens with in mind — nothing here came from a live render of a site, dates and scores were read through search extraction, and some stack claims are inferred. When a session has network access, `/awards:research <url>` re-verifies a site and updates its card; the reports stay as provenance.
