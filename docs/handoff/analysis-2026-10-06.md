# Awards plugin: why generated sites fall short of the corpus, and what to build next

2026-10-06. Produced by a multi-agent read of the plugin (8 readers, a synthesis, one adversarial verifier per proposal). `site/` paths refer to the untracked dogfood builds in the working tree. The Now items are planned in `docs/superpowers/plans/2026-10-06-now-items.md`.

Paths are relative to `plugins/awards/` unless they start with `site/`, `docs/` or `evals/`. All 20 proposals came back from verification as **revise**. The roadmap below uses the revised text.

## 1. Verdict

1. The most likely biggest loss happens before the plugin runs at all. In the only measured A/B, 6 of 6 realistic builds made zero Skill calls, so the user got base-model taste with plugin paperwork on top.
2. When the workflow does run, the model never sees a real reference site. There are 0 images under `references/`. The only images any skill opens are six synthetic Alder Workshop frames, and the jury compares pixels against prose.
3. Divergence goes into the costume (WORLD and SIGNATURE). Every build gets the same wireframe: wordmark-left nav, a label over a two-line h1 at bottom left, and a filled plus outline CTA pair.
4. The plugin seeds its own house style:
   - a `/ 01` eyebrow in the scaffold;
   - unconditional tracked-caps labels;
   - fixed expo easings;
   - a "usual picks" kit of 2019-era staples;
   - an open-font whitelist that has become the new reflex.
5. The gates measure the floor, not the ceiling. All 72 audit rules are prohibitions, the first real aesthetic judgement comes at the end, and the 8-slot fix list fills with a11y items. The cheapest fixes are mostly deletions and small edits, not new machinery.

## 2. Diagnosis (ranked)

Corrections from verification are applied. Three claims in the first draft were refuted and are marked below.

1. **The workflow often does not run.**
   - `docs/handoff/visual-comparison-2026-09-22.md:44-47`: zero Skill calls in 6/6 builds. `docs/handoff/todo.md:22-25` lists this as uninvestigated.
   - Dogfood builds degraded to reading SKILL.md files with a non-forked jury (`site/two/AWARDS.md:76,103`) or ran unattended (site/four, site/five).
   - Layout-variance discipline came from the external design-taste-frontend skill (`site/five/DESIGN.md:66-74`).
   - Smoke evals pass only because they use one-line prompts, Read/Glob/Grep/Skill, and 8 turns (`evals/trigger-portfolio-site/prompt.md:1-8`).
   - The one full-tools eval tells the model to "work through the full awards process" (`evals/build-antarctic-site/prompt.md`). No eval tests an unled brief.

2. **There is no visual bar.**
   - `references/` holds 0 png/webp/jpg (re-checked).
   - The only images opened are the Alder frames: cream ground, Georgia serif, tracked clay labels (`references/patterns/visual-composition.md:3-12`; `recipes/_shared/composition.css:2-12`). That is the editorial cluster impeccable calls "already spent".
   - The jury's specificity and ceiling checks read card text (`skills/jury/SKILL.md:84`).
   - 72 real capture folders exist only in the author's gitignored `.awards/research/` (586 MB, 11 of them empty). No design phase reads them, and user projects never have them.

3. **Divergence covers the costume, not the composition.**
   - Concept's randomness covers WORLD and SIGNATURE only (`skills/concept/SKILL.md:75-82`). Nav, hero skeleton and chapter layout are never varied.
   - The template hero appears in site/two through site/five (`site/four/index.html:71` `hero__eyebrow`; `site/five/index.html:53` `hero__brand`; `site/four/AWARDS.md:32`; `site/five/AWARDS.md:40`). The shared chapter order is mostly a test artefact, since all five builds had the same brief.
   - Concept reads only §7/§8 of each card (`skills/concept/SKILL.md:38`; `references/sites/_index.md:86`). On tech-lens cards, §8 Take is all technique (boc, eugeniagrab, aqualoqa).
   - system ignores the chosen neighbours and reads the-line, leo-parpeix and slosh-seltzer for every project (`skills/system/SKILL.md:43`).
   - "One signature, every other move quiet" (`skills/concept/SKILL.md:136`) is read as "quiet layout", so every non-signature chapter becomes the default block.
   - There is no layout-family vocabulary or repetition cap anywhere (grep for "layout family" or "zigzag" returns nothing).

4. **The plugin has its own house style.**
   - Scaffold hero: `<p class="label">/ 01</p>` (`assets/scaffold/vite-vanilla/index.html:25`). The audit reports it clean.
   - `skills/system/SKILL.md:61` sets labels as texture (uppercase, .08em) unconditionally.
   - `skills/system/SKILL.md:93-94` hard-codes the expo curves and 1400 ms. site/five copies `0.16,1,0.3,1`/1400 ms verbatim and site/four has the same curve.
   - `skills/system/SKILL.md:60` states The Line's `12.1528vw` clamp as a rule.
   - "Usual picks by role" (`skills/structure/SKILL.md:87-93`) lists counter preloader, overlay nav, two-speed cursor and magnetic CTA.
   - Fonts:
     - The font whitelist has become the reflex: site/one Bodoni Moda, Martian Mono and Mona Sans; site/two Schibsted Grotesk, Big Shoulders Display and Azeret Mono; site/three Archivo. All are listed in `scripts/data/reflex-fonts.json:13-17`.
     - All five builds add a mono third face.
     - Instrument Serif is listed as both a reflex and an alternative (`reflex-fonts.json:5` vs `:17`).
   - *Refuted:* palette anchoring to the template hexes. The builds derive their own grounds (`#d9ded0`, `#eef1f2`, `#111314`).
   - *Refuted:* "builds ship system fonts". They self-host via @fontsource or local woff2.

5. **The gates measure the floor, and they arrive late.**
   - All 72 rules are prohibitions (`scripts/data/rules.json`).
   - The mid-build static checkpoint is self-review for "material defects", one batch, against Alder (`skills/craft/SKILL.md:126`).
   - The first independent aesthetic verdict is the final jury (`skills/craft/SKILL.md:110`).
   - Fix list: at most 8 items, with design seams ordered last behind fidelity, walk and P0/P1 (`references/report-template.md:34,157-158`). ship never redesigns and adds no fixes of its own (`skills/ship/SKILL.md:12,41`).
   - Restraint rules stack: lowest rung (`skills/craft/SKILL.md:174`), lowest dosage (`references/patterns/hero-archetypes.md:183`). Result: competent, minimal pages.
   - All three juried dogfood sites stopped at `fix`, 7.08–7.59 (`site/two/AWARDS.md:77`, `site/five/AWARDS.md:86,102`). None shipped.

6. **No material path for builds without assets.**
   - "Assets: none" is accepted as final (`site/five/AWARDS.md:20`).
   - `references/asset-pipeline.md:5-7` asks art-direction questions only.
   - No contract line forces a named imagery strategy, so "type on a flat ground" happens without anyone choosing it.
   - The human-preference evidence for imagery is thin: one of three briefs favoured the baseline, and every reason field is blank (`docs/handoff/visual-comparison-2026-09-22.md:170-181`).

7. **Components are re-skinned recipes.**
   - Adapting means "rename, re-token, re-time" (`skills/component/SKILL.md:93`; `skills/motion/SKILL.md:132`; `skills/craft/SKILL.md:162`).
   - The motion table "What you re-decide" lists only knobs (`skills/motion/SKILL.md:134-150`), so form and choreography carry over.
   - Stale catalogue lines route distinctive recipes to generic fallbacks (`references/patterns/components-catalog.md:136,227,286`).
   - The canonical whole-page exemplar contains eyebrows and "No. 01" (`recipes/complete-editorial-composition/index.html:21,37,89`), and `recipes/editorial-image-text/style.css:13` has a border-left accent.

8. **The lexical audit is easy to bypass.**
   - L05 matches only exact class names (`scripts/audit.mjs:365`), so `hero__eyebrow` and `hero__brand` pass.
   - X07 is P3 and misses the `/ 01` form (`scripts/audit.mjs:392`).
   - The Exceptions parse runs to end of file (`scripts/audit.mjs:112`). This is low impact, since `## Exceptions` is the last heading in the template.
   - Rendered C01 checks only body text against its background (`scripts/audit.mjs:454,495`).

9. **Nothing measures pixels or divergence.**
   - Build graders are regex, file_exists, or llm on text.
   - Jury graders check format only (`evals/jury-generic-saas/graders/disposition-line.md`), so a generic SaaS page that gets `ship` still passes.
   - The human visual benchmark had 14 of 18 ties, all with blank reasons.

10. **Context weight: real but secondary, and drift is unobserved.**
    - Concept loads about 230 KB (`skills/concept/SKILL.md:37-44`): _index 47 KB, narrative-structures 40 KB, hero-archetypes 28 KB.
    - *Refuted:* "the contract sits only in compacted context". Every phase re-reads AWARDS.md and DESIGN.md from disk (`skills/motion/SKILL.md:18`, `skills/structure/SKILL.md:27,38`).
    - The 151 of 150 turns event was a turn-budget problem.

## 3. Creativity pipeline today, and where ambition leaks

| Step | What happens | Leak |
|---|---|---|
| Intake (`skills/craft/SKILL.md:77-79`) | Brief; may not ask about fonts, colours or effects | No slot for sites or images the user likes, so taste only arrives if volunteered |
| Concept (`skills/concept/SKILL.md:37-113`) | `_index` → 3 nearest cards by class → reads §7/§8 only → names 2 ruts → DIVERGENCE take/refuse → model writes 7 worlds → `scripts/roll.mjs` shuffles the indices and deals 3 → one AskUserQuestion round | Worlds come from one model pass, so the deal cannot leave the model's distribution. LEAD is the lowest dealt index (`roll.mjs:44-47`), so the earliest-written idea leads. "A fourth from the undealt pool" (`skills/concept/SKILL.md:100`) let site/four and site/five lock world 1. Take lines are technique. No composition is dealt, and the hero template rut is never named. |
| System (`skills/system/SKILL.md:43-110`) | Tokens from WORLD; faces from the alternatives table | Same three calibration cards every time; fixed motion literals; The Line's clamp; unconditional labels; no `--h2`/`--h3`/`--body` |
| Structure (`skills/structure/SKILL.md:63-95,274-282`) | Page map, archetype, recipe ids, skeleton | Offers 9 of the 13 archetypes (`:75` vs `hero-archetypes.md:167-181`); staple-kit table; no Layout column or variety rule; skeleton adapted from recipe `index.html` |
| Static checkpoint (`skills/craft/SKILL.md:126`) | First real pixels; self-review against Alder; one batch | Looks for defects, not ambition; the reviewer is the builder |
| Motion / WebGL / component | Adapt recipes by knobs | Recipe silhouette carries over; signature finish (low-poly stone, flat fire in site/four) is first seen at the final jury |
| Jury → ship (`skills/jury/SKILL.md:84,125-130`; `skills/ship/SKILL.md:12`) | Forked, evidence-first, compared against prose; ≤8 fixes; no redesign; ≤2 rounds | Design seams crowded out; no ceiling input; a build can sit at "fix" indefinitely |

Strengths to keep:
- the contract frame (THESIS, two ruts, SIGNATURE, memory and naming tests);
- worlds drawn from the audience's culture and material families;
- the category-rut table (`references/anti-patterns.md:19-31`);
- rich §3/§4 measurables in the cards (`the-line.md:48-68`);
- the seeded roll;
- the forked inventory-first jury.

Five builds produced five genuinely different palettes and worlds. The strongest frames (site/five desktop-50 relief map, site/three woven shader) reach reference level exactly where a signature was executed with conviction.

## 4. impeccable and tasteskill vs awards

| Mechanism | impeccable | tasteskill | awards |
|---|---|---|---|
| Detection taxonomy | 67 patterns, 9 families, detector plus overlay | 60-item self-attested pre-flight and production tells | Comparable: slop scan mirrors the families, with 72 rules executed by audit plus hook (stronger) |
| Outside entropy in direction | Curated external worlds dealt as challengers, plus "raise" | Seeded draws from fixed catalogues (simulated RNG) | Real seeded PRNG, but it only shuffles model-authored worlds (gap) |
| Rendition-cluster check | "Treat the first palette as spent", names the editorial cluster | Bans the premium-consumer hex family | Cream and italic serif are separate judge rows; no combined register, and the plugin steers into it (gap) |
| Visual bar | QUALITY BAR board per world; comps; comp-diff hero gate at 72% | Image-generation first; image-to-code | None; the synthetic Alder frames only (gap) |
| Composition variance | Comp-led three-way composition choice | ≥4 layout families per 8 sections, ≤2 zigzags, no split header, eyebrows capped at ceil(sections/3) by CSS signature | Pacing rule only (`skills/structure/SKILL.md:66`) (gap) |
| Metadata costume | Partly | Explicit list: No. 01, middle dots, locale strips, version footers | L05/X07 only, lexical (gap) |
| Assets | asset-producer agent, "never substitute chrome" | Image tool first; a text-only page is incomplete | Questions only (gap) |
| Finish review | Fresh reviewer with mandatory TYPE/MATERIAL/GROUND rows, pixel-sampled ground, ceiling check | none | Forked jury, inventory first, D/U/C/Co plus dev rubric; has type and costume rows, but no ceiling or ground check |
| Fonts | "Faces as objects from the subject's world" | Rotate away from the previous project | Reflex list is stronger than tasteskill's (it flags Satoshi and Geist), but the whitelist is the new reflex |
| Concept depth, a11y, motion floor, verified recipes, award-calibrated weights | Partial | None | Clearly better |

In short, awards already matches or beats both on detection and enforcement. What it lacks is all on the generation side: outside stimuli, a visual bar, composition variance, a material path, and a ceiling review.
