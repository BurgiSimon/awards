# Handoff

Everything a future session needs to continue the `awards` plugin without re-deriving it.

| File | Read it for |
|---|---|
| `state.md` | What exists, where, what was verified and how, what was not, environment facts, the build's timeline |
| `todo.md` | The open items, ordered by value |
| `decisions.md` | Decisions taken with the user and the architectural choices with their reasons, plus the working conventions |
| `plan.md` | The approved plan: research findings (§5–§6), architecture (§7), the individual plan for the core skill and each sub-skill (§8), reference and recipe catalogues (§10), scripts (§11), evals (§12), phases (§13), risks (§14) |
| `research/` | The raw research reports the site cards were distilled from |

Start with `state.md`, then `todo.md`. The plugin's own documentation lives in `README.md` (root), `plugins/awards/README.md`, `plugins/awards/references/README.md`, `plugins/awards/recipes/README.md` and `plugins/awards/evals/README.md`.
