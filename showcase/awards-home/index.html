Nothing ships unproofed.

awards is a plugin for Claude Code and Codex that designs and builds websites in the league of award winners, then hands each build to a jury that never saw it being made. The jury scores captures, not intentions. Until it has, and a ship report exists, the work is only a proof.

{{skills.count}} skills, run in order.

One skill holds the brief and hands each phase to the next. Skills cannot call one another, so every hand-off is a written line in the build's AWARDS.md, and every phase leaves a file the next one reads before it starts.

Outside the run

{{rules.count}} rules, measured before anyone looks.

The audit is deterministic: the same page gives the same findings, by file and line. It reads type, colour, motion, accessibility, layout, performance and the browser's own surfaces, and twenty-one of its rules catch the habits a generator falls into when nobody decided anything. Rendered, it measures every text against what is actually behind it, at three widths.

The press check.

A juror who watched the work being made scores the intention. So the jury runs forked, in a fresh context, with the builders' notes withheld. It reads the captures first, writes down what the first viewport shows and what a visitor would remember an hour later, and only then opens the contract, which can lower a score and never raise one.

{{recipes.count}} recipes, each verified in a browser.

Every recipe is a working page with a verification script: built, served and driven through its states in headless Chromium before it counts. Skills adapt them, never paste them: keep the mechanism, change the metaphor, the material or the trigger. Behind them sits a corpus of {{corpus.sites}} analysed award winners, read for principles to take and signatures to refuse.
