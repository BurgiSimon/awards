Your site, proofed before anyone sees it.

awards is a plugin for Claude Code and Codex that holds a website to a written contract, runs 89 audit rules after every edit, captures the page at three widths and hands it to a juror in a fresh context who never saw it built.

Install it: two commands in either client

Claude Code

  1. /plugin marketplace add burgisimon/awards
  2. /plugin install awards@awards

Codex

  1. codex plugin marketplace add burgisimon/awards
  2. codex plugin add awards@awards

Every phase leaves a file the next one reads

A build runs nine phases in three runs. Skills cannot call each other, so each phase ends by writing its decision to disk, and the next phase starts from that file rather than from a summary of the conversation. AWARDS.md carries every decision from one session to the next.

Decide

  1. Brief

    At most three questions: what only this subject can prove, who reads it and where, and what a visitor should do.

    AWARDS.md, Brief

  2. Concept

    Seven candidate worlds; a seeded roll deals three and a conventional exit; you lock one, written down as a direction contract.

    AWARDS.md, Direction contract

  3. System

    One type contract, two to four colour tokens, self-hosted fonts and every browser surface themed.

    DESIGN.md, tokens.css

Build

  1. Structure

    Chapters with beats, one interruption, a designed close and a 404, as semantic HTML before any motion.

    AWARDS.md, Page map; the skeleton

  2. Stack

    Vite by default; Lenis and GSAP on one ticker, and a hook that lets captures drive the page.

    window.__awards

  3. Motion

    One authored moment per chapter, each with a reduced-motion tier, and never a global animation kill.

    AWARDS.md, Motion score

  4. WebGL

    Only where a beat needs depth: its own lazy chunk, a DOM mirror, and a page that works without it.

    The GL chunk, or a written decline

Judge

  1. Jury

    A juror in a fresh context reads the captures before the contract, scores four axes and ends on one word.

    .awards/jury/, Jury log

  2. Ship

    The fixes in one batch, the audit clean or every exception explained, the performance measured.

    .awards/ship/, Ship log

The jury reads the captures before the contract

Each round ends with a juror that never saw the page being built, so nothing in the building conversation can argue for it. It describes the first viewport in its own words, then reads the contract, scores four axes the way award entries are weighed plus six developer criteria, and ends on one word.

How the jury weighs a page
AxisWeight
Design40 %
Usability30 %
Creativity20 %
Content10 %

The one word it ends on

ship
Weighted 7.2 or higher, no axis under 6.8, no P0 or P1 audit finding, every contract row kept.
fix
Weighted 6.8 to 7.19, or one axis under 6.8, or a P0 or P1 finding, or a broken contract row.
rebuild
Weighted under 6.8, a source site a juror could name, a memory test that returns only a mood, or a thesis not visible on screen one.
recapture
The evidence is missing, blank or broken, so no score exists yet.

This juror scores about 0.7 below the published award on the same sites, by design. A ship here means a page cleared that stricter floor, not that it would win.

89 rules, run after every edit

The audit is deterministic, with no model in the loop. In Claude Code a hook runs its fast subset after every edit in a project that has an AWARDS.md and stays silent everywhere else; Codex runs it after each batch of edits. Add --render and it opens the page in Chromium at three widths to measure what only a browser can.

Eight families
FamilyRulesOne thing it catches
Type8a reflex face, a fonts CDN link, display type with no ceiling
Colour5text under 4.5:1 against what is actually behind it
Motion8no reduced-motion branch, or a global animation kill
Accessibility18a phone control smaller than 44 by 44 pixels
Layout10a whole viewport with nothing in it
Performance9layout shift above 0.1 while the page loads
Browser surfaces10a default selection colour, no theme colour, no favicon
Slop scan21glow, glass, framework purple, bounce easing, a hero-metric row

21 of the rules look for the habits a generator falls into when nobody made a decision. When two or more of those families remain on a page, the jury caps Creativity at 6.

Install it before your next site

Claude Code

  1. /plugin marketplace add burgisimon/awards
  2. /plugin install awards@awards

Codex

  1. codex plugin marketplace add burgisimon/awards
  2. codex plugin add awards@awards

Then ask for a site in your own words, or start it with /awards:craft in Claude Code and $awards:craft in Codex. Builds need Node 22.12 or later, or 24 LTS; captures and the rendered audit need Playwright with Chromium. The full requirements
